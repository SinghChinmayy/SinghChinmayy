# Repository guidance

## GitHub landing page

`README.md` is the landing page for my GitHub profile and this public repository. Keep it readable as a personal introduction first, with links to my website and verified public projects. It should reflect my honest positioning as an early-career software engineer focused on backend development, infrastructure, and systems engineering.

When updating the portfolio, keep the README aligned with the public site. Do not describe me as senior or as an expert, and do not present the Kidney Care engineering prototype as a patient-facing or production medical product.

## Responsive website guidance

Keep the portfolio mobile-first and verify changes at approximately 360px, 390px, 768px, 1024px, and 1440px widths.

- Prevent horizontal scrolling, clipped text, and overflow from cards, code blocks, images, metadata, or long URLs.
- Stack hero content, project cards, grouped tech tags, and CTA controls naturally on small screens.
- Keep touch targets at least 44px tall where practical, with visible keyboard focus states.
- Use readable body text and restrained heading sizes; do not solve mobile layout with excessive shrinking.
- Prefer `min-width` desktop enhancements over desktop-first overrides when adding new responsive styles.
- Test both light and dark themes, the mobile navigation open/close behavior, theme toggle, and reduced-motion behavior.
- Keep homepage summaries short and scannable; move detailed explanations into project case studies and articles.
