# Repository guidance

`README.md` is the landing page for my GitHub profile and this public repository. Keep it readable as a personal introduction first, with links to my website and verified public projects. It should reflect my honest positioning as an early-career software engineer focused on backend development, infrastructure, and systems engineering.

When updating the portfolio, keep the README aligned with the public site. Do not describe me as senior or as an expert, and do not present the Kidney Care engineering prototype as a patient-facing or production medical product.
