Nextpage is an early-stage macOS app. Stage 1 is local only: it makes no AI requests
and no sync requests, and both are planned rather than built.

## What's Built

- **Navigation**: Folder and Markdown-file navigation for a folder you choose
- **Editing**: Create, read, edit, rename, and delete flows
- **Preview**: GitHub-flavored Markdown rendering, including task lists
- **Autosave**: Debounced atomic saves, flushed on file switch and quit
- **External changes**: Detection of outside edits with recoverable conflicts
- **Folder access**: Security-scoped access to the selected journal folder

## What's Next

- **AI-assisted journaling**: A design for global and per-project AI prompt settings exists in the repository; it is planned, not implemented
- **Git synchronization**: Planned for a later stage
- **Manual smoke test**: Stage 1 is only complete once the create, edit, preview, rename, delete, relaunch, and external-edit flows are confirmed on a user-selected folder
