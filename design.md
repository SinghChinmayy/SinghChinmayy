# Visual system

This portfolio uses a minimal engineering-notebook direction: calm surfaces, editorial reading widths, and explicit metadata that makes project scope and status easy to understand.

- Canvas: `#F7F8FA` in light mode, with white cards and neutral borders.
- Ink: `#17212B`; secondary copy uses a muted blue-gray for comfortable reading.
- Accent: `#276EF1`, used for actions, active navigation, and links.
- Type: Inter for body and headings; a small monospace layer is reserved for dates, status labels, and technical metadata.
- Layout: one shared content width, modest borders, no gradients or decorative effects, and cards used only where they help scanning.
- Interaction: visible focus rings, minimum comfortable touch targets, a keyboard-operable mobile menu, and reduced-motion support.
- Content: projects are presented as truthful case studies with constraints, decisions, current state, and lessons. No production claims are implied by prototypes.
