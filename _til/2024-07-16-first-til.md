Today I learned how to add a new collection in Jekyll for short-form notes. Just add this to your `_config.yml`:

```yaml
collections:
  til:
    output: true
    permalink: /til/:title/
```

Then create a `_til/` folder and add your notes as markdown files. Jekyll will build them at `/til/` automatically!
